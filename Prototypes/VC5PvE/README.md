# 森钟战术 · 独立 PvE 原型

Unity 2021.3.33f1c1 / URP 12.1.13 / Windows x64。工程位于 `Prototypes/VC5PvE`，拥有独立 Assets、Packages、ProjectSettings 和构建入口。

## 直接试玩

**2026-10-03 当前版直接在 Unity 试玩，本轮没有重新打包。** Unity Hub 添加本目录 `Prototypes/VC5PvE`，使用 Unity 2021.3.33f1c1。

- 从开始界面进入：打开 `Assets/VC5PvE/Scenes/Title.unity`，按 Play，再点“开始游戏”。
- 直接进首关：打开 `Assets/VC5PvE/Scenes/ForestRuins.unity`，按 Play，部署后点“开始战斗”。
- `Builds/Windows/森钟战术.exe` 是10月1日旧包，不包含本次美术与交互修改。

- 部署：拖动三名己方棋子至 B–D / 7–8 格交换位置，也可先点棋子再点格子，然后点“开始战斗”。
- 基础行动：点己方棋子，在棋子旁弹出的菜单中选择移动、普通攻击或急救，鼠标指向目标时查看范围和结果，点击合法目标立即执行。菜单显示费用、步数、伤害/射程与禁用原因；每次花费1 AP，战士/法使移动最多1格，辅助最多2格。空地、ESC、选卡或切阶段关闭菜单。
- 卡牌：先选棋子（中立牌的执行者），点卡或拖牌即可高亮有效目标；拖向目标时查看范围、路径、落点和 HP/AP/状态变化，松手立即出牌。也可点卡后点击合法目标直接执行。专属牌自动使用对应角色；掩护拖向哪名友军就由该友军执行。突入拖向敌人，根据指针方向选择合法落点并预览击退。无效目标、`Esc`、取消不消耗资源。
- 换牌：每轮首次行动前点“换牌1次”，再点一张牌。保留手牌，每轮补至6张。
- 结束：点“结束回合”；所有存活棋子 AP 为0时也会自动交接。敌军行动期间锁定玩家操作。
- 胜败：全部敌军或己方倒下进入结算，可重新挑战或返回标题。

## 打开源码与重建

1. Unity Hub 添加本目录，使用 Unity 2021.3.33f1c1 打开，等待导入。
2. 打开 `Assets/VC5PvE/Scenes/Title.unity` 后按 Play。
3. 菜单 `VC5PvE > Build Windows x64` 会重建场景并生成 `Builds/Windows/森钟战术.exe`，结果写入 `Logs/VC5PvE-Windows-build-report.txt`。

Builder 生成 Prefab、URP 材质和 Title/ForestRuins 两个场景；手工修改生成物时需同步 `Editor/PrototypeSceneBuilder.cs`。棋盘、HUD和动画在运行时创建。当前为Linear色彩空间、明亮森林远景、手绘植被/苔藓遗迹与实时3D棋盘；棋子复用旧工程v2/v3透明立绘。角色透明shader、Sprites/Default与URP/Unlit保留在Graphics Settings，Lit通过场景材质保留。
