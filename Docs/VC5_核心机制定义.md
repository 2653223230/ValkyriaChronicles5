# VC5 核心机制定义

> **版本**: v1.0  
> **日期**: 2026-05-26  
> **适用范围**: 所有英雄、卡牌、地块设计

---

## 一、英雄死亡机制

### 1.1 基本规则

| 项目 | 规则 |
|------|------|
| **死亡条件** | 英雄生命值降至 0 或以下时，**立即死亡** |
| **死亡后果** | 英雄**退场**，本局游戏**不可复活**（除非特殊机制） |
| **卡牌处理** | 死亡英雄的手牌和牌库全部移除游戏 |
| **效果终止** | 该英雄的所有持续效果、召唤物、造物立即消失 |

### 1.2 特殊复活机制

目前仅有以下英雄拥有复活/免死机制：

| 英雄 | 机制名称 | 触发条件 | 效果 | 限制 |
|------|---------|---------|------|------|
| **狂龙** | 龙魂 | 升华阶段，生命≤3时触发 | 化为龙魂（无敌但无法攻击），1回合后复活为5生命 | 每场战斗仅触发1次 |
| **坚硬黏黏2** | 幼崽复活 | 升华永续加成 | 幼崽死亡时50%概率复活为1/1 | 每只幼崽全局仅触发1次 |

**设计原则**：复活机制是**稀有特性**，仅作为特定英雄的核心玩法，不通用。

## 二、胜利条件

### 2.1 得分来源

| 行为 | 得分 | 说明 |
|------|------|------|
| **击杀敌方单位** | +5 分 | 击杀敌方英雄或召唤物 |
| **控制得分地块** | +1 分/回合 | 每回合开始时，站在得分地块上获得 |

### 2.2 胜利条件

**目标分数**: 先达到 **15 分** 的玩家获胜

**回合上限**: 若达到 **20 回合** 仍未有人达到15分，则**分数高者获胜**

**平局处理**: 同分时，剩余总生命值高者获胜

## 三、回合流程

```
回合开始
  ↓
[抽牌阶段] 抽2张牌
  ↓
[资源阶段] 获得资源（龙息+1/流风+1/零件+1等）
  ↓
[地块效果] 触发所在地块效果
  ↓
[觉醒检查] 检查是否满足觉醒条件
  ↓
[行动阶段] 使用卡牌、移动、攻击（顺序任意）
  ↓
[造物/召唤物行动] 造物和召唤物自动行动
  ↓
回合结束
```

## 四、攻击与伤害

### 4.1 攻击流程

1. **选择目标**: 目标必须在攻击距离内
2. **伤害计算**: 基础攻击力 + 加成 - 目标防御
3. **伤害类型**: 
   - 物理伤害：可被护盾、闪避（如有）抵消
   - 龙焰/风伤/元素伤害：无视护盾，直接扣减生命

### 4.2 伤害减免上限

- 单次伤害最低为 **1**（不可完全免疫）
- 伤害减免效果最高叠加至 **50%**

## 五、控制与状态效果

### 5.1 状态效果列表

| 状态 | 效果 | 持续时间 |
|------|------|---------|
| **眩晕** | 无法行动（不能移动、攻击、使用卡牌） | 1 回合 |
| **束缚** | 无法移动，可以攻击和使用卡牌 | 1 回合 |
| **沉默** | 无法使用法术卡，可以攻击 | 1 回合 |
| **流血** | 回合开始时失去 1 生命 | 3 回合或直到治疗 |
| **中毒** | 回合开始时失去 2 生命 | 2 回合 |
| **尖锐** | 攻击时额外造成 1 伤害 | 永久（可叠加） |
| **护盾** | 抵消等量伤害 | 直到被打破 |
| **威压** | 见造物章节 | 持续存在 |

### 5.2 状态叠加规则

- **同类型负面状态**：不叠加，取最高效果，刷新持续时间
- **同类型正面状态**：可叠加（如尖锐）
- **眩晕+束缚**：眩晕优先（无法行动包含无法移动）

## 六、造物与召唤物规则

### 6.1 造物（齿轮家族）

| 项目 | 规则 |
|------|------|
| **数量上限** | 每个英雄最多 2 个（升华后 3 个） |
| **生命值** | 独立计算，归零即破坏 |
| **行动** | 每回合自动攻击，不占用英雄行动点 |
| **回收** | 破坏时回收 50% 零件（向上取整） |
| **威压** | 见下方定义 |

**威压效果**：
- 敌人在威压造物攻击距离内时：
  - 对非威压目标伤害 -1
  - 对威压造物伤害 +1
  - 攻击威压造物后，下回合移动力 -1

### 6.2 召唤物（符文/荒野）

| 项目 | 规则 |
|------|------|
| **数量上限** | 符文：最多 5 个；荒野：最多 3 个 |
| **生命值** | 独立计算，归零即消失 |
| **行动** | 每回合自动行动或需指令 |
| **击杀积分** | 击杀召唤物获得 2 分 |

## 七、地块规则

### 7.1 地块数量

- 每局游戏随机出现 **2 个地块**
- 地块分布在棋盘左右两区

### 7.2 地块控制

- 英雄停留在地块上即视为**控制**
- 每回合开始时，控制者获得地块效果
- 地块效果每回合只能触发一次（由控制者触发）

---

## 八、卡组规则

### 8.1 卡组构成

- 每个英雄有独立的卡组
- 卡组固定 20 张牌
- 初始手牌 3 张

### 8.2 抽牌与弃牌

- 每回合抽 2 张牌
- 手牌上限 10 张，超出需弃至 10 张
- 牌库抽空后，弃牌堆洗牌形成新牌库
