## 2. 联合开发：你要注意什么

### 统一「录入规范」（最重要）

约定成文，两人都按同一模板来，避免一人写 Bootstrap、一人写 asset。

**建议固定：**

| 项目 | 约定 |
|------|------|
| **卡 id** | 全局唯一、小写+下划线，如 `vc5_warrior_charge`；**创建后不改** |
| **资源路径** | 如 `Assets/TcgEngine/Resources/Cards/vc5/card_{id}.asset` |
| **注册表** | 每新增/改卡 **必须** 同步 `Docs/vc5_card_registry/*.csv` |
| **禁止** | 新卡进 `Vc5SlimeBootstrap`；不要改 `CardData.Load` 等核心加载逻辑（除非两人商量） |
| **能力** | 优先复用已有 `Effect*` / `AbilityData`；新效果单独脚本 + 新 ability 资源 |

### Git / Unity 冲突

1. **`.asset` + `.meta` 必须成对提交**  
   只提交 `.asset` 不提交 `.meta` 会在对方工程里产生新 GUID，引用会断。

2. **一人一批卡、分支开发**  
   例如 `feature/card-vc5-xxx`，合并前在 Unity 里打开场景看 Console、跑一局试玩。

3. **少改同一个大文件**  
   `Vc5SlimeBootstrap.cs`、`GameLogic.cs`、`CollectionPanel.cs` 等尽量只有一人动；**新卡只加新 `.asset` + 新 CSV 行**，冲突会少很多。

4. **CSV 合并**  
   `cards_registry.csv` 多人同时加行容易冲突。习惯：**每人只追加新行、不改别人行的 id**；合并冲突时按行保留双方新增即可。

5. **不要 Force Push `main`**  
   Unity 资源合并失败时，用新提交修，不要硬覆盖。

6. **Unity 版本一致**  
   同一 `ProjectVersion`（你们 2021.3），避免 `.asset` 格式差异。

### 打包与试玩一致

目前注册表读的是工程里 `Docs/vc5_card_registry`；**正式包若也要吃注册表**，以后可约定把 CSV 同步进 `Resources`（可列为后续改进）。  
联合开发阶段：**以 `.asset` 为真相来源**，CSV 作台账；这样即使注册表在包里读不到，**asset 卡仍会进包**。

## 3. 可以直接发给朋友的「交代说明」

下面这段你可以复制微调后发给他：

---

**VC5 卡牌录入约定（请严格遵守）**

1. **新卡一律用 Unity 资源，不用 runtime 代码注册**  
   - 创建 `CardData` `.asset`，放在 `Assets/TcgEngine/Resources/Cards/vc5/`（或组内约定的子目录）。  
   - **不要**在 `Vc5SlimeBootstrap.cs` 里为新卡写 `RegisterCard` / `CreateInstance`。

2. **每张卡必须有唯一 `id`**  
   - 与文件名、注册表、`DeckData` 引用一致；命名：`vc5_系列_效果` 小写英文。

3. **必须同步注册表**  
   - 在 `Docs/vc5_card_registry/cards_registry.csv`（英雄则 `heroes_registry.csv`）增加一行：`enabled=1`，`source=asset`，`asset_path` 填完整路径。  
   - 或在 Unity 菜单：**TcgEngine → 卡牌注册表 → 从游戏导出到 CSV**（会保留已有 `enabled`/`notes`）。

4. **提交 Git 时**  
   - 每个新 `.asset` 连同其 **`.meta` 一起提交**。  
   - 尽量 **一张卡或一小批卡一个分支**，PR 里写清 `id` 列表。  
   - 不要改与卡无关的大文件；能力逻辑用 **新脚本 / 新 Ability 资源**，少改公共逻辑。

5. **实现前先看文档模板**  
   - 卡 id、名称、类型、费用、攻血移攻距、字段标签、效果步骤、是否快速行动、是否进组卡池。  
   - 优先复用已有 effect；全新机制再新建 `Effect*.cs` 并在 PR 说明。

6. **自测**  
   - Unity 打开工程 → Play → 组卡/收藏里能看到；Console 无 `DataLoader` / 重复 id 报错。  
   - 若删卡测试：注册表 `enabled=0`，不要删磁盘 `.asset`（除非确定无引用）。

7. **有歧义时**  
   - 以工程内已有 `vc5` 黏黏 `.asset`（若有）或 `Docs/vc5_card_registry/README.md` 为准；不要引入第二套 Excel/导入流程 unless 组内同意。
