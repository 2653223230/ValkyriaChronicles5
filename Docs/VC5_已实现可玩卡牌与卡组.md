# VC5 已实现可玩卡牌与卡组

更新时间：2026-09-16

版本快照：`demo_v2_20260830` 封存包仍为 B、C、C3 三套卡组。当前工作区新增独立 R4、B-AI1（已实现，待人工试玩），不改变封存包；本次未构建或发布 v3。

本文档记录当前工程中已经实现、可以在游戏里直接选择试玩的 VC5 Demo 卡组、棋子和卡牌。后续如果要修改卡牌效果，优先修改本文档，再按本文档同步代码。

2026-09-16：独立 B-AI1 已接入，规则验证与人工验收边界见文末及 v3 进度记录；原 B/R4 不覆盖。

## 使用方式

- 数据注册入口：`Assets/TcgEngine/Scripts/Data/Vc5DemoBootstrap.cs`
- 卡组会自动加入 `GameplayData.free_decks`，在 TestP2P/卡组选择下拉中可直接选择。
- 当前注册五个试玩卡组（验收进度见 v3 发布计划）：
  - `deck_vc5_demo_mobile_assault`：VC5 Demo 机动突击
  - `deck_vc5_demo_ranged_pressure`：VC5 Demo 射击压制
  - `deck_vc5_demo_ranged_pressure_c3`：VC5 Demo 射击压制 C3，独立新卡组，不覆盖旧射击压制
  - `deck_vc5_demo_command_r4`：VC5 Demo 机动支援与阵地狙击 R4，独立于原 C3，20 张构筑＋3 种临时指令
  - `deck_vc5_demo_steady_assault`：VC5 Demo 稳步推进战团 B-AI1，独立于原 B，20 张构筑；玩家和 AI 均可使用
- 旧 B/C 交互：大多数牌采用“先选择己方角色，再选择敌人或格子”的两步操作；能自动完成的移动牌只需要选择己方角色。
- 旧 B/C 攻击类卡牌第二步只能选择该角色攻击范围内的敌人；点击超出范围或不合法目标时会显示无效目标提示。
- 新 C3 交互：拖到己方棋子上预览，松开执行；仅战术移动、强行军还需选择落点，伤害牌自动选择敌人。

## 公共规则说明

| 项目 | 当前实现 |
|---|---|
| 棋子基础属性 | 攻击、生命、移动力、攻击范围 |
| 卡牌基础属性 | ID、名称、费用、是否快速行动、张数、目标、效果 |
| 快速行动 | `fast_action=true`，不消耗主要行动且不切换当前行动玩家 |
| 普通行动 | 卡牌或非快速角色技能完整结算后，自动把行动权交给尚未放弃的对手；不等同于主动放弃本回合后续行动 |
| 攻击与反击 | B/C/C3 Demo 攻击牌只结算卡面写明的单向伤害；被攻击棋子不会自动反击。只有以后明确写有反击的卡牌或技能才能造成反击伤害 |
| 棋盘占格 | 画面中的一个实际格子最多存在一个单位；敌我逻辑坐标不同也不能在画面上重叠 |
| 旧 B/C 护甲 | 使用 `StatusType.Armor`，数值表示每次减伤量，保持既有行为 |
| R4 护盾 | 独立可消耗护盾，抵消伤害后减少；C3-V3R4 的掩护部署/指令无上限相加并刷新至下一完整回合末；B-AI1 仍取剩余值与新值较大者 |
| 临时射程 | 旧 C 使用 `Vc5AttackRangeBonus`；C3 临时校准使用 `Vc5C3TemporaryRange`，整回合结束清除且不叠加 |
| 永久射程 | C3 改装使用 `Vc5C3PermanentRange`，永久可叠加；与临时状态分别存储，总攻击范围统一汇总 |
| 自动推进 | 自动移动到更接近规则文档所列 7 格得分区的空格；坐标统一读取 `Vc5ScoringZone` |
| 自动后撤 | 自动移动到更远离最近敌人的空格 |
| 贴身移动 | 自动寻找目标敌人相邻且画面中未被任何单位占用的空格；没有合法空格时该目标不可选 |

### 自动判定与预览

- 六张非精确移动牌只需拖到己方棋子松开。必须发生真实拖动，单击不出牌；不受旧“屏幕下方 25% 不能出牌”的限制。
- 最近敌人按实际六边格距离、当前生命低者、稳定在场生成顺序排序；最高/最低生命按当前生命、距离、稳定顺序排序。
- C3 使用实际棋盘空格的最短可达路线，不能穿过敌我占用格。自动射击落点并列时优先得分区，再靠近中心，再按坐标稳定排序；没有结果不出牌、不扣费。
- 护卫警戒先结算；若击杀了移动射击原目标，按最终位置的最近敌人规则重选存活目标。胜负已成立则停止后续伤害。
- 机动火力只在至少一个目标实际受伤后消耗；所有伤害被防护抵消时保留。有效格边界先统一到玩家 0 的棋盘坐标，避免 AI 视角进入不存在的边缘格。
- 悬停行动者：青框；自动目标：红框与预计伤害/击破；射程：半透明区域，新增范围亮色外圈；移动：路线箭头、半透明落点与名字；精确移动：显示合法空格，指向空格后显示被动结果。
- 预览使用 `Game.CloneNew` 对局副本，调用真实 C3 结算及 `GameLogic.DamageCard`，涵盖护盾、护壳、免疫和警戒后重选；不修改真实手牌、法力、生命、位置或状态。
- 状态条显示临时射程、永久改装层数、待用机动火力、本回合已移动/已用警戒。旧 C3 草稿没有独立图标素材，本轮以范围外圈、落点框和状态文字表达。

## 已知 Demo 化处理

为了让初版 demo 的出牌操作更直接，以下效果做了简化：

- “向前/向己方方向移动”没有要求玩家理解棋盘朝向，当前实现为自动向争夺区推进或自动远离最近敌人。
- 多角色协同牌尽量减少选择次数：`齐射` 只选敌人，系统自动找能攻击该目标的己方角色。
- 旧 B/C 部分棋子被动暂未做成完整监听式规则，当前以卡牌效果或角色说明体现；新 C3 的三种被动均已实现，不属于该占位情况。
