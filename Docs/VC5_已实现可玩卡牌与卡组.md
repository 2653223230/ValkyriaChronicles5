# VC5 已实现可玩卡牌与卡组

更新时间：2026-08-20

本文档记录当前工程中已经实现、可以在游戏里直接选择试玩的 VC5 Demo 卡组、棋子和卡牌。后续如果要修改卡牌效果，优先修改本文档，再按本文档同步代码。

## 使用方式

- 数据注册入口：`Assets/TcgEngine/Scripts/Data/Vc5DemoBootstrap.cs`
- 卡组会自动加入 `GameplayData.free_decks`，在 TestP2P/卡组选择下拉中可直接选择。
- 当前新增两个试玩卡组：
  - `deck_vc5_demo_mobile_assault`：VC5 Demo 机动突击
  - `deck_vc5_demo_ranged_pressure`：VC5 Demo 射击压制
- 通用交互原则：大多数牌采用“先选择己方角色，再选择敌人或格子”的两步操作；能自动完成的移动牌只需要选择己方角色。
- 攻击类卡牌第二步只能选择该角色攻击范围内的敌人；点击超出范围或不合法目标时会显示无效目标提示。

## 公共规则说明

| 项目 | 当前实现 |
|---|---|
| 棋子基础属性 | 攻击、生命、移动力、攻击范围 |
| 卡牌基础属性 | ID、名称、费用、是否快速行动、张数、目标、效果 |
| 快速行动 | `fast_action=true`，不消耗主要行动且不切换当前行动玩家 |
| 普通行动 | 卡牌或非快速角色技能完整结算后，自动把行动权交给尚未放弃的对手；不等同于主动放弃本回合后续行动 |
| 攻击与反击 | B/C Demo 攻击牌只结算卡面写明的单向伤害；被攻击棋子不会自动反击。只有以后明确写有反击的卡牌或技能才能造成反击伤害 |
| 棋盘占格 | 画面中的一个实际格子最多存在一个单位；敌我逻辑坐标不同也不能在画面上重叠 |
| 护盾 | 使用 `StatusType.Armor`，数值表示减伤量，当前 demo 持续 1 回合 |
| 临时射程 | 使用 `StatusType.Vc5AttackRangeBonus`，当前 demo 持续 1 回合 |
| 自动推进 | 自动移动到更接近规则文档所列 7 格得分区的空格；坐标统一读取 `Vc5ScoringZone` |
| 自动后撤 | 自动移动到更远离最近敌人的空格 |
| 贴身移动 | 自动寻找目标敌人相邻且画面中未被任何单位占用的空格；没有合法空格时该目标不可选 |

## 已知 Demo 化处理

为了让初版 demo 的出牌操作更直接，以下效果做了简化：

- “向前/向己方方向移动”没有要求玩家理解棋盘朝向，当前实现为自动向争夺区推进或自动远离最近敌人。
- 多角色协同牌尽量减少选择次数：`齐射` 只选敌人，系统自动找能攻击该目标的己方角色。
- 部分棋子被动暂未做成完整监听式规则，当前以卡牌效果或角色说明体现，避免抢走“打牌驱动棋子行为”的核心体验。
