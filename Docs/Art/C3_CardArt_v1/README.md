# C3 功能卡图 v1 审核稿

状态：2026-08-28 策划已批准八张 v1 卡图，已接入 Unity 并完成自动验证。此目录保留审核源文件；游戏只导入八张独立 PNG，不导入总览、ZIP 或 SVG。

## 设计约定

- 浅灰底、深色粗线。己方用青色圆形，敌方用红色菱形，空格用六边形。
- 移动使用粗箭头和虚线落点，伤害使用射击线与命中闪光，新增射程使用黄色外圈。
- 血条表示当前生命的相对高低；示意格数量、血条分段不作为游戏固定数值。
- 卡图不包含费用、完整卡框或角色特征。必要短标注只说明效果，不替代卡牌描述及实际效果预览。
- 临时校准用钟表和“本回合”，改装瞄具用机械改装符号和“永久”区分。
- 不改变已实现卡牌效果。运行时资源放在 `Assets/TcgEngine/Resources/VC5/DemoArt`，按卡牌 ID 绑定。
