# v2demo试玩反馈

## 银河眼哥：
1.卡组不平衡，新的射手c3太强
2.个别的操作不是很顺心
3.引导差
4.平衡差、数值差
5.对其他模块不是很清晰（因为战力碾压？）
6.机动卡组没改，玩家错误使用会造成体验差
7.建议引入回合最低保底操作？（试图解决牌烂、没牌了没事干的问题）


## cc：（只体验了c3VS未知卡组）
1.和ai对狙教学必死一个
2.弃牌时，通过点击来选取，选中的上浮（再次点击上浮的卡牌可以取消对此卡牌的选择），选完然后点确定来弃牌
3.能用的牌高亮，不能用的灰掉
4.总体比上个版本成功，打牌流畅多了，后续需要决定走杀戮尖塔方向还是游戏王md方向
5.卡牌间配合太少，缺少combo，多是单卡单能力

## 神秘路人a：（只体验了c3VS未知卡组）
1.字体大一点
2.有时候ai不会移动棋子，是卡手还是bug
3.让玩家摆放棋子，顺便认识棋子，介绍功能推荐占位
4.推荐策划玩下陷阵之志（战棋）、昆特牌（二维卡牌，田忌赛马）、散樱乱舞（桌游），获得灵感
5.卡组之间数值不平衡
6.c3卡组高费牌太强，抽多了玩起来有点卡手，希望多一些卡手时的操作，比如亏牌不亏费，丢x张牌可以xx，不消耗费用
--兽医策划补充：为了解决这个问题可以让棋子获得一些丢弃xx手牌获得一张攻击、移动牌等技能，棋子有了特性之后，combo也可以通过此实现
7.可以考虑牌缩模，棋子涨模
8.棋子死后没复活的话，高手玩家只要会集火，局势就会很快一边倒

## 无言：（只体验了c3VS未知卡组）
1.ai怎么不攻击，不知道是卡手还是bug
2.对移动射击的处理逻辑不清楚
3.一人出一张牌，要说明清楚
4.感觉操作比较局限
--兽医策划补充：我看到他似乎在想当前的费用，怎么分配给手里的卡牌，有几种出法，但发现好像只有一种
5.引导部分文字太多，他没注意看，很多在游戏中遇到的疑问其实都写在引导里，他觉得引导不够直观，没有记忆点，都靠自己领悟
6.感觉卡图没起到帮助理解游戏的作用，主要靠阅读文字。
