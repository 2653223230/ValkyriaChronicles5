# 地块类型扩展补充文档

> 本文档补充说明 9 种地块类型的详细设计，每局游戏从中随机选取 3 种出现。

---

| 类型编号 | 地块名称 | 类别 | 核心效果 | 策略倾向 |
|---------|---------|------|---------|---------|
| T01 | 得分地块 | 胜利型 | 每回合 +1 分 | 快速取胜 |
| T02 | 觉醒加速地块 | 成长型 | 觉醒进度 +1 | 后期爆发 |
| T03 | 行动干扰地块 | 控制型 | 麻痹敌方单位 | 压制对方 |
| T04 | 法力源泉地块 | 资源型 | 每回合 +1 法力 | 资源压制 |

## 一、胜利型地块

### T01 得分地块（Score Tile）

| 属性 | 说明 |
|------|------|
| **视觉标识** | 金色/黄色高亮，金币图标 |
| **效果** | 回合结束时，占领方获得 1 分（`kill_count += 1`） |
| **叠加规则** | 不叠加，每回合最多获得 1 分 |
| **策略价值** | 高 -- 直接推进胜利条件 |

**详细规则**：
- 占领判定：回合结束时，地块 `Slot` 上有己方单位
- 得分时机：`EndOfTurn` 阶段
- 得分效果：`player.kill_count += 1`
- 地块得分与击杀得分独立计算

**胜利路径对比**：
- 纯击杀：击杀 3 个单位（3 × 3 = 9 分）
- 纯得分：占领 9 个回合（9 × 1 = 9 分）
- 混合路线：击杀 + 地块组合

## 二、成长型地块

### T02 觉醒加速地块（Awakening Boost Tile）

| 属性 | 说明 |
|------|------|
| **视觉标识** | 蓝色/紫色高亮，光芒图标 |
| **效果** | 回合结束时，占领方所有英雄的觉醒进度 +1 |
| **叠加规则** | 不叠加，每回合每个英雄最多 +1 |
| **策略价值** | 中高 -- 加速觉醒进程 |

**详细规则**：
- 加速对所有英雄生效，不限于地块上的单位
- 加速效果对已完成的觉醒阶段无效
- 觉醒进度 = 自然积累进度 + 地块加速进度

---

## 三、控制型地块

### T03 行动干扰地块（Disruption Tile）

| 属性 | 说明 |
|------|------|
| **视觉标识** | 红色/暗红色高亮，锁链图标 |
| **效果** | 回合结束时，占领方选择对方 1 个单位，使其下回合「麻痹」 |
| **叠加规则** | 不叠加，每回合最多干扰 1 个单位 |
| **策略价值** | 中 -- 限制对方关键单位 |

**详细规则**：
- 麻痹效果：`StatusType.Paralysed`，持续 1 回合
- 被麻痹单位无法攻击、移动、使用技能
- 通过 `SelectorType.SelectTarget` 选择目标

---

## 四、资源型地块

### T04 法力源泉地块（Mana Spring Tile）

| 属性 | 说明 |
|------|------|
| **视觉标识** | 青色/蓝色高亮，水滴图标 |
| **效果** | 回合结束时，占领方获得 1 点额外法力（下回合可用） |
| **叠加规则** | 不叠加，每回合最多 +1 法力 |
| **策略价值** | 中高 -- 法力优势可打出更多卡牌 |

**详细规则**：
- 法力增加时机：`EndOfTurn` 阶段，增加到下回合的法力上限
- 效果：`player.mana_max += 1`（临时增加，仅下回合有效）
- 与正常法力恢复叠加

### T08 抽牌神殿地块（Card Shrine Tile）

| 属性 | 说明 |
|------|------|
| **视觉标识** | 橙色/金色高亮，书本图标 |
| **效果** | 回合结束时，占领方抽 1 张牌 |
| **叠加规则** | 不叠加，每回合最多抽 1 张 |
| **策略价值** | 高 -- 手牌优势，更多选择 |

**详细规则**：
- 抽牌时机：`EndOfTurn` 阶段
- 效果：执行一次 `DrawCard()` 操作
- 如果手牌已满（5 张），效果无效

## 五、战斗型地块

### T05 战斗祭坛地块（Battle Altar Tile）

| 属性 | 说明 |
|------|------|
| **视觉标识** | 深红色高亮，剑图标 |
| **效果** | 占领方所有单位攻击力 +1 |
| **叠加规则** | 不叠加，全场效果唯一 |
| **策略价值** | 高 -- 直接提升输出能力 |

**详细规则**：
- 效果范围：占领方所有场上单位（包括英雄和角色）
- 效果类型：`ongoing_trait`，攻击力 +1
- 单位离开地块后效果消失
- 多个单位占领不叠加

## 六、防御型地块

### T06 生命圣泉地块（Life Spring Tile）

| 属性 | 说明 |
|------|------|
| **视觉标识** | 绿色高亮，心形图标 |
| **效果** | 回合结束时，占领方所有单位恢复 2 点生命 |
| **叠加规则** | 不叠加，每回合最多恢复 2 生命 |
| **策略价值** | 中 -- 续航能力 |

**详细规则**：
- 恢复时机：`EndOfTurn` 阶段
- 恢复范围：占领方所有场上单位
- 不会超过生命值上限

### T09 护盾堡垒地块（Shield Fortress Tile）

| 属性 | 说明 |
|------|------|
| **视觉标识** | 银色/白色高亮，盾牌图标 |
| **效果** | 占领方所有单位获得 2 点护盾（抵挡 2 点伤害） |
| **叠加规则** | 不叠加，护盾可累积但每回合最多 +2 |
| **策略价值** | 中 -- 减伤保护 |

**详细规则**：
- 护盾机制：受到伤害时优先扣除护盾
- 护盾持续到被消耗完或单位死亡
- 每回合占领可累积护盾（最多叠加到 6 点）

## 地块生成规则更新

### 随机选取机制

```
GenerateTiles():
  1. 定义 9 种地块类型的候选池
  2. 从候选池中随机选取 3 种（不重复）
  3. 将选出的 3 种地块分配到 A/B/C 三区
  4. 每区随机选取具体位置（遵循原有分布规则）
```

### 选取概率

- 每种地块类型被选中的概率：3/9 = 33.3%
- 特定组合出现的概率：1/C(9,3) = 1/84 ≈ 1.2%
- 这意味着每局游戏的地块组合几乎是独一无二的

### 策略影响

玩家需要在游戏开始时：
1. **识别当前局的 3 种地块类型**
2. **评估各地块类型的价值**（根据己方卡组）
3. **制定本局的争夺优先级**

例如：
- 如果出现了「得分地块 + 战斗祭坛 + 生命圣泉」，进攻型卡组占优
- 如果出现了「觉醒加速地块 + 法力源泉 + 抽牌神殿」，后期卡组占优
- 如果出现了「行动干扰地块 + 风行之径 + 护盾堡垒」，控制型卡组占优

## 代码实现更新

### TileType 枚举扩展

```csharp
public enum TileType
{
    None = 0,
    Score = 1,              // 得分地块 T01
    AwakeningBoost = 2,     // 觉醒加速地块 T02
    Disruption = 3,         // 行动干扰地块 T03
    ManaSpring = 4,         // 法力源泉地块 T04
    BattleAltar = 5,        // 战斗祭坛地块 T05
    LifeSpring = 6,         // 生命圣泉地块 T06
    WindPath = 7,           // 风行之径地块 T07
    CardShrine = 8,         // 抽牌神殿地块 T08
    ShieldFortress = 9,     // 护盾堡垒地块 T09
}
```

### 地块效果结算扩展

在 `ResolveTiles()` 方法中扩展 switch case：

```csharp
switch (tile.type)
{
    case TileType.Score:
        owner.kill_count += 1;
        break;
    case TileType.AwakeningBoost:
        // 觉醒进度 +1
        break;
    case TileType.Disruption:
        // 触发麻痹效果
        break;
    case TileType.ManaSpring:
        owner.mana_max += 1;
        break;
    case TileType.BattleAltar:
        // 攻击力 +1
        break;
    case TileType.LifeSpring:
        // 恢复 2 生命
        break;
    case TileType.WindPath:
        // 移动力 +1
        break;
    case TileType.CardShrine:
        // 抽 1 张牌
        break;
    case TileType.ShieldFortress:
        // 护盾 +2
        break;
}
```
