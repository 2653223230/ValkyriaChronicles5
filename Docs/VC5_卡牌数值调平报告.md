## 一、数值基准体系

### 1.1 价值点数（PV）系统

基于炉石/影之诗的研究，为 VC5 建立以下价值点数体系：

| 维度 | PV 值 | 说明 |
|------|-------|------|
| 1 点攻击力 | 1 PV | 基础攻击属性 |
| 1 点生命值 | 1 PV | 基础生命属性 |
| 1 点法力费用 | ≈ 2 PV | 法力是核心资源 |
| 抽 1 张牌 | 2 PV | 手牌优势 |
| 造成 1 点伤害（可选目标） | 1 PV | 精确伤害 |
| 造成 1 点伤害（AOE） | 0.5 PV/目标 | 范围伤害按目标数折算 |
| 1 点治疗 | 0.5 PV | 治疗价值低于伤害 |
| 1 层粘液 | 0.5 PV | 持续性 Debuff |
| 1 层尖锐 | 1 PV | 临时攻击增益 |
| 1 层流血 | 0.5 PV/回合 | 持续伤害 |
| 1 层护盾 | 1 PV | 一次性减伤 |
| 移动力 +1 | 0.5 PV | 战棋特有维度 |
| 攻击距离 +1 | 0.5 PV | 战棋特有维度 |
| 麻痹 1 回合 | 1.5 PV | 强力控制 |
| 1 点 HP 费用 | 0.5 PV | 自伤补偿 |
| 弃 1 张牌 | -1.5 PV | 手牌损失 |

### 1.2 法力费用与效果价值对照表

| 法力费用 | 基础价值（PV） | 典型效果 |
|---------|---------------|---------|
| 0 费 | 0.5 PV | 极微弱效果，需有条件限制 |
| 1 费 | 2 PV | 1 点伤害 / 1 层粘液 / 微弱 buff |
| 2 费 | 4 PV | 2 点伤害 / 1 伤害+抽 1 牌 / 中等 buff |
| 3 费 | 6 PV | 3 点伤害 / 召唤随从 / 强力 buff |

### 1.3 VC5 特殊维度

VC5 与传统 TCG 的关键差异：

- **六边形战棋**：移动力和攻击距离是独立维度
- **英雄系统**：英雄不消耗法力打出，是持续在场单位
- **主行动限制**：每阶段 1 个非快速行动，快速行动不消耗主行动
- **地块系统**：环境效果提供额外价值

### 3.4 0 费卡牌设计原则

当前项目有 **5 张 0 法力卡牌**，这是数值平衡的最大风险点：

| 卡牌 | 当前费用 | 有其他费用 | 实际成本 |
|------|---------|-----------|---------|
| 黏黏重击 | 0 法力 | 2 HP | 1 PV |
| 粘液附着 | 0 法力 | 无 | **0 PV** ⚠️ |
| 英勇冲锋 | 0 法力 | 3 HP | 1.5 PV |
| 鲜血旋流 | 0 法力 | 当前HP-1 HP | 极高 |
| 战吼 | 0 法力 | 无 | **0 PV** ⚠️ |
| 战士的献祭 | 0 法力 | 1 HP | 0.5 PV |

**核心问题**：粘液附着和战吼是 0 费 + 0 其他成本 + 快速行动，这意味着玩家可以免费使用且不消耗主行动。

**建议原则**：
- 0 费卡牌**必须**有 HP 费用或其他非 trivial 成本
- 快速行动的 0 费卡牌尤其危险（不消耗主行动 + 不消耗法力）
- 如果要保持 0 费，效果应该极弱（如仅 1 层粘液，不带麻痹）

## 四、数值调平建议汇总

### 4.1 黏黏流调整

| 卡牌 | 调整项 | 当前值 → 建议值 | 理由 |
|------|--------|----------------|------|

## 六、后续建议
