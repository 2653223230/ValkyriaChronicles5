## 一、齿轮家族（机械/零件）

### 1.1 家族基础设定

| 项目 | 内容 |
|------|------|
| **家族名** | 齿轮家族 |
| **英文代号** | Gear |
| **主题风格** | 蒸汽朋克、机械造物、零件组装 |
| **视觉特征** | 黄铜齿轮、蒸汽管道、巨型机甲、零件散落 |
| **背景设定** | 来自工业城邦的工程师和机械战士，通过收集零件组装出强大的机械造物来碾压对手 |

### 1.2 核心机制：零件 + 造物

#### 1.2.1 零件

**零件规则**：
- 零件是一种**积累型资源**，无上限
- 获取方式：使用卡牌、攻击敌人、回合开始时、拾取战场零件
- 用途：消耗零件组装造物、强化已有造物、修复造物

**零件获取方式**：

| 行为 | 零件获取 |
|------|---------|
| 回合开始 | +1 零件 |
| 使用齿轮家族卡牌 | +1~3 零件（卡牌描述） |
| 攻击命中敌人 | +1 零件 |
| 造物被破坏 | 回收 50% 已投入零件（向上取整） |
| 拾取「零件箱」地块 | +3 零件 |

#### 1.2.2 造物

**造物是什么**：
- 造物是部署在战场上的**独立实体**，占据 1 个格子
- 造物拥有自己的**生命值**，可被敌人攻击
- 造物被破坏时**不会对英雄造成伤害**，但会回收部分零件
- 每个英雄同时最多控制 **2 个造物**

**威压**：拥有威压的造物会强制改变敌人的行为模式。当敌人在威压造物的攻击距离内时：
- 该敌人对威压造物以外的目标造成的伤害 -1
- 该敌人对威压造物造成的伤害 +1（吸引火力但不强制）
- 威压造物被攻击时，攻击者下回合移动力 -1

**造物属性**：

| 属性 | 说明 |
|------|------|
| **生命值** | 被攻击时扣减，归零则造物被破坏 |
| **攻击力** | 造物每回合可自动攻击（攻击距离内最近敌人） |
| **攻击距离** | 造物的攻击范围 |
| **特殊效果** | 每个造物有独特被动效果 |

**造物分类**：

| 造物名 | 零件费用 | 生命值 | 攻击力 | 攻击距离 | 特殊效果 |
|--------|---------|--------|--------|---------|---------|
| 炮台 | 5 | 6 | 2 | 3 | 每回合自动攻击最近敌人 |
| 护盾发生器 | 6 | 8 | 0 | 0 | 每回合为相邻友军提供 2 护盾 |
| 传送带 | 3 | 4 | 0 | 0 | 相邻友军移动力 +2 |
| 陷阱 | 4 | 3 | 0 | 0 | 敌人经过时受到 3 伤害并眩晕 1 回合 |
| 维修站 | 5 | 6 | 0 | 0 | 每回合恢复相邻友军 2 生命 |
| 巨型机甲 | 15 | 20 | 4 | 2 | 威压；攻击附带眩晕 |
| 蒸汽巨炮 | 12 | 5 | 6 | 5 | 无法移动；每回合攻击所有攻击距离内敌人 |
| 铁壁要塞 | 18 | 30 | 0 | 0 | 威压；相邻敌人对非铁壁要塞目标伤害 -2；无法攻击 |
| 自爆机器人 | 3 | 3 | 0 | 0 | 被破坏时对周围所有敌人造成 5 伤害 |
| 精英机甲 | 20 | 25 | 5 | 2 | 威压；攻击附带 2 龙焰伤害；每回合恢复 3 生命 |

**造物破坏规则**：
- 造物生命值归零时被**破坏并移除**
- 造物被破坏时，建造者**回收 50% 已投入零件**（向上取整）
- 例如：投入 15 零件建造巨型机甲，被破坏时回收 8 零件
- 造物**不占用英雄的行动点**，每回合自动行动
- 造物**可以被友军卡牌修复**（恢复生命值）

#### 1.2.3 造物强化

- 消耗零件可以强化已有造物：
  - 消耗 3 零件：造物生命值 +3
  - 消耗 5 零件：造物攻击力 +1
  - 消耗 4 零件：修复造物至满生命值

### 1.3 英雄设计（5人）

#### 1.3.1 机械工程师

| 属性 | 数值 |
|------|------|
| **英雄名** | 机械工程师 |
| **hero_id** | `vc5_gear_engineer` |
| **攻击** | 1 |
| **生命** | 12 |
| **移动** | 3 |
| **攻击距离** | 2 |

**核心机制**: 零件 + 造物部署 + 快速组装

**被动**: 回合开始时额外获得 1 零件；造物建造费用 -1 零件

**技能**: 每回合 1 次，在相邻空格组装 1 个「炮台」（消耗 5 零件）

**觉醒设计**：

| 阶段 | 条件 | 效果 |
|------|------|------|
| 初醒 | 累计组装造物 ≥ 3 个 | 立即免费组装 1 个炮台，且本回合所有造物攻击力 +1（当回合+永续） |
| 进阶 | 累计消耗零件 ≥ 40 个 | 造物建造费用 -2 零件（永续） |
| 升华 | **处于进阶状态** 且 同时控制 ≥ 2 个造物 | 所有造物立即攻击 1 次并恢复 5 生命（当回合）；造物上限 +1（最多 3 个，永续） |

## 二、符文家族（奥术/法师）

### 2.1 家族基础设定

| 项目 | 内容 |
|------|------|
| **家族名** | 符文家族 |
| **英文代号** | Rune |
| **主题风格** | 神秘符文、奥术魔法、法术连锁 |
| **视觉特征** | 漂浮符文、魔法阵、法杖、奥术能量 |
| **背景设定** | 古老魔法学院的法师，通过绘制符文来操控奥术能量，擅长复杂的法术组合 |

### 2.2 核心机制：符文

**符文类型**：
- 符文分为 4 种元素：**火**🔥、**水**💧、**风**🌪️、**土**🪨
- 每种符文独立计算层数，上限各 8 层
- 符文通过卡牌、技能、被动获得

**符文效果**：

| 符文组合 | 效果名称 | 效果描述 |
|---------|---------|---------|
| 火≥2 | 燃烧 | 攻击附加火符文层数的火焰伤害 |
| 水≥2 | 治愈 | 回合开始时恢复水符文层数的生命 |
| 风≥2 | 迅捷 | 移动力 +1，可穿越敌人 |
| 土≥2 | 护盾 | 获得等同于土符文层数的护盾 |
| 火+水≥2+2 | 蒸汽 | 造成范围伤害并治疗自己 |
| 风+土≥2+2 | 沙尘 | 敌人攻击距离 -1 |
| 火+风≥2+2 | 烈焰风暴 | 对路径上所有敌人造成伤害 |
| 水+土≥2+2 | 沼泽 | 敌人移动力 -2 |
| 火+水+风+土≥2+2+2+2 | 元素爆发 | 对所有敌人造成 5 伤害，自己恢复 5 生命 |

**符文连锁**：
- 连续使用同元素卡牌，效果叠加
- 3 连击：该元素符文获取 +1
- 5 连击：该元素效果翻倍

### 2.3 英雄设计（5人）

#### 2.3.1 元素法师

| **英雄名** | 元素法师 |

### 3.2 核心机制：野性

**野性值**：
- 野性是一种**动态资源**，范围 0-100
- 高野性（50-100）：「兽性」状态，攻击力和移动力提升，但失去部分控制
- 低野性（0-50）：「人性」状态，可以使用法术和策略卡牌
- 野性通过战斗、受到伤害、使用特定卡牌变化

**野性效果**：

| 野性范围 | 状态 | 效果 |
|---------|------|------|
| 0-25 | 人性态 | 每回合第 1 张法术卡效果翻倍；攻击力 -1 |
| 26-49 | 平衡态 | 正常使用所有卡牌，无特殊效果 |
| 50-74 | 兽性态 | 攻击力 +1，移动力 +1；法术卡费用 +1 |
| 75-100 | 狂暴态 | 攻击力 +2，移动力 +2；只能使用攻击卡和响应卡 |

**野兽伙伴**：
- 每个荒野英雄可以召唤 1 个野兽伙伴（狼、熊、鹰、蛇等）
- 伙伴独立行动，有自己的生命值和攻击力
- 伙伴死亡时，野性 +20

**生态互动**：
- 战场上的植物、地形可以被利用
- 站在草地上：每回合恢复 1 生命
- 站在树林中：获得隐蔽（对树林中的敌人，攻击距离 -1，最低为 1）
