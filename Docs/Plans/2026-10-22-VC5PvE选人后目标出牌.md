# 先选棋子，再直接对目标出牌：实施计划

状态：用户已批准方案一并要求实施。先记录文档，再修改代码；沿用现有VC5PvE工程与工作区，不覆盖三关尚未提交增量。不打包、不自动提交推送。

## 已批准的交互

- 唯一主顺序：选己方棋子/左侧头像→点牌或基础技能→点最终目标。卡牌可拖向最终目标松手执行，拖拽是同一流程的快捷输入。
- 本轮改为最终目标出牌，覆盖2026-10-04“拖给执行者再选目标”约定。点击卡牌即进入当前行动者的目标选择，不再仅查看；拖向其他棋子不改变行动者。
- 第一次进入己方战斗时需要明确选人；同一角色执行后保持选中，切人需玩家明确操作。角色死亡时清空行动者，不静默改选别人。
- 攻击牌→敌人；移动牌→落点；支援牌→其他友军；掩护→自身棋子或自己的队伍头像。点牌本身不支付或施放掩护。
- 破阵突入：先选/拖至合法落点，再点击该落点邻接的敌人完成。第一步不移动、不扣费、不伤害；取消不结算，不自动挑敌人。
- 回收战术：选定执行者后点击卡牌直接打开弃牌选择，确认才付费；拖拽快捷方式松手到自身也打开同一选择。天赋回收保持已批准支援后回收/跳过流程。
- 目标选择期间点击左侧头像：若它是当前行动的合法友军目标，则执行（掩护/鼓舞/协防/急救）；否则取消当前瞄准并切换行动者。拖拽不触发切人。右键或ESC取消当前选择，不扣资源。
- 手牌位置不重排：当前角色可合法施放的牌亮起/轻微上浮，不可用牌变暗但仍可查看原因。维持个人AP、合法目标/视线、实际费用、卡面、基础行动次数和三关成长规则。
- 持续显示当前行动者头像与姓名；箭头从当前行动者指向目标；拖拽牌面淡出不遮棋盘。头顶蓝菱形预览即将支付的AP，合法范围及真实结果继续来自同一ActionPlanner/BattleResolver克隆。
- 本轮实施方案一，不擅自增加方案二/三或卡面头像自动切人的另一套操作。
