# 共享AP布局与范围预览 V2

2026-11-04。用户已批准补齐技能图示后实施，现已接入Unity；下面保留审核设计，实际交付差异见末尾。

## 本轮反馈与设计约束

- 出战小队、选中角色数值、技能、射程图解与基础行动状态全部集中左侧；取消右侧角色栏。
- 删除“下一轮威胁”文字列表。战场通过敌人抬武器/蓄力、瞄准连线、目标脚下图标、炮击区域脉冲、移动终点虚影传达。默认简洁提示，指向敌人可强化其单独意图；用图标/线型辅助颜色辨认。
- 共享AP常驻手牌正上方，拖牌预览显示虚耗和剩余数，取消立即恢复。
- 拖攻击牌到棋子：显示该执行者当前合法攻击范围、可命中敌人；指向敌人后才显示准确伤害。
- 拖机动牌到棋子：显示当前合法移动格和障碍；松手锁定执行者后选择落点，悬停落点显示路径。
- 拖突击牌到棋子：先显示可移动格；锁定执行者并指向落点后，以该落点显示攻击范围。未来射程用橙色虚线、移动格用青色实线，避免误认为在当前位置已经能打到。最终确认前不扣AP和手牌。
- 护盾/治疗拖入队员时显示增益预览，不显示无关攻击/移动范围。
- 弃牌选择继续沿用V1：默认不选、选中上浮、只弃所选，未选保留，下轮补至5张。

## 审核图边界

使用实际晴岚截图作锁定战场参考，UI与范围/意图标记原生可编辑。范围叠层是表现示意，Unity实现时必须使用实际合法格计算，不能把图中示意格固化为规则。动画以关键状态与时序说明交付，不把静态截图称为已播放动画或运行验收。
