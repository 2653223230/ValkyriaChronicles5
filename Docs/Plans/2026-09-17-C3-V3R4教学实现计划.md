# C3-V3R4 实操教学实现计划

> **执行要求：** 按本文逐项实施；先更新设计与进度文档，再写失败测试和最小实现，最后回填真实验证结果。

**目标：** 将已审核的本地 Figma 十状态教学接入 R4 Solo Demo，让玩家在教学对局中真实完成出牌、技能移动和战术筹划，结束或跳过后重新开始一局干净的正式对战。

**实现边界：** 复用现有 `Vc5DemoTutorialOverlay`、真实卡牌/技能/选择器和 Solo 场景重开流程；原 C3 六状态教学保留。R4 教学只影响玩家使用 `deck_vc5_demo_command_r4` 的本地 Solo Demo，不新增联网消息，不修改 Multiplayer/P2P 规则。

**设计依据：** 本地 Figma `VC5 Demo 玩家引导 UI`，页面 `C3-V3R4 教学引导审核 v2`（`84:2`），状态 `84:5`～`84:14`；2026-09-17 策划已确认按其手工修订后的版本实现。

## 全局约束

- 教学以打牌为核心，技能只作为辅助说明；不教授固定 Combo。
- 教学推进依赖真实玩家动作，不用定时器伪造成功。
- 教学局起手最左侧固定一张 R4《移动射击》；其余牌保持洗牌后的相对顺序。
- 《移动射击》教学结算后保留本次教学的玩家操作机会，使玩家能继续完成快速技能教学；该例外只存在于 R4 教学演练，不改变正式对战规则。
- 教学完成或任意时刻跳过，都先断开教学局并回到 `Menu`，再由菜单自动新建一局正式 Solo 对战；正式局重新洗牌、棋子/分数/法力复位、AI 正常行动，且不会立刻再次弹出教学。禁止仅重载 `Game` 场景，因为本地服务器生命周期不会随该方式可靠重建。
- 原 C3 教学、非 Demo Solo、AI、Multiplayer/P2P 不受影响。
