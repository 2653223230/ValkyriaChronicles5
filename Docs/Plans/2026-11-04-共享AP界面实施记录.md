# 共享 AP 界面 V2 实施记录

日期：2026-11-04

## 实施范围

依据 `2026-11-04-共享AP交互V2实施.md`、`2026-11-04-共享AP布局与范围预览V2.md` 与 Figma 审核截图 `Docs/ArtReviews/2026-11-04-SharedAP-Figma/review-01.png`、`review-03-v2.png`。本次仅修改分配的 SharedHud、SharedRoleDiagram、新增 `.meta`，以及公共 CardHandView、CardDragInput、PartyPanelView 的默认兼容扩展；不修改共享控制器或规则，不启动 Unity，不提交。

## 目标实现

- 左侧集中小队状态、当前角色武器与技能图解，预留约 380 px；武器范围格示意读取规则射程；技能图解表达方向与效果关系，不把审核图里的格子当作真实棋盘合法格。
- 共享 AP 固定显示在手牌正上方，目标位置约 y=790；去除右侧文字威胁栏，保留棋盘上的真实预览。
- 卡牌点击时不要求先选执行者；根据 `CanExecuteCard(unitId, cardId)` 显示合法队员，拖到队员时切换预览执行者；拖动过程显示预览 AP。
- 弃牌默认零选中，点牌上浮；确认仅弃所选，未选牌保留；返回/取消退出选择，下轮补至 5 张。移除“最多保留 2 张”交互。
- 移除短步/普攻行动菜单入口，保留控制器兼容属性及旧 UI 公共方法，个人 AP 默认行为不变。
- 先锋推敌与护盾至少 2 的图示、射手架弩前后数据/移动解除图示、术师敌方移位及武器溅射分别可辨识。

## 代理接口约定

UI 对接共享控制器的 `DiscardIds`、`ToggleDiscard(string)`、两阶段 `BeginEndTurn()` / `ConfirmEndTurn()`、`Cancel()`、纯查询 `CanExecuteCard(string,string)`，以及拖牌时的 `PreviewExecutorId`。如接口签名调整，以控制器代理已回报契约为准，不扩展到控制器文件。

## 验证边界

按任务要求只进行静态检查（代码/接口引用、差异与空白检查）；不运行 Unity、EditMode/PlayMode 或编译。运行验证缺口及接口不匹配会在交付说明中明确记录。
