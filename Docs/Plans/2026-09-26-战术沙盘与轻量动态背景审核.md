# 战术沙盘与轻量动态背景审核

> 状态：已按批准稿接入 Unity，聚焦自动检查及正式场景复查完成；待策划真人与设备验收。

## 目标与范围

让当前 2D 日式立牌对局更有战术桌游氛围，不影响格子、目标、卡牌和按钮辨识。首轮仅覆盖 C3-V3R4 对 B-AI1 的 Demo 演练/正式 AI 对局；不将共享 Game 场景的背景全局替换，不改变原 C3、其他正式对局、规则、AI 或 Multiplayer/P2P。

## 视觉与动态拟定值

- 暗蓝灰指挥桌面：两侧地图纸、机械面板与暖色灯光，中央低对比留白。背景底图为内置 imagegen 新生成的纯背景插画，不包含棋格、角色、卡牌或 UI。
- 棋盘增加深色实体底板、细金属边框、微立体格子边缘；格内等高线式细纹仅为装饰，不表示新增地形规则。七个得分格保留“得分区”并用金色轮廓辨识。
- 六名棋子及蓝攻/红命样式沿用批准的立牌方案；原 UI 使用实际截图裁切参照，不重新排布。审核合成里的裁切背景色块不进入 Unity。
- 远景底图水平 ±3 px、24 秒往返；少量边缘浮尘约 14 粒，低透明缓慢上浮；暖色灯光 6 秒柔和明暗；得分区轮廓 4 秒轻微呼吸。数值为当前 1469 px 预览宽度下的拟定幅度，实施时按视口比例换算。
- 棋盘、棋子逻辑坐标、碰撞和 UI 不随背景移动。合法目标/攻击范围高亮优先于得分呼吸；不遮文字，不闪烁，不用重后处理。下方三幅轮廓仅为静态关键帧，不是已运行的动画。

## 已批准实现安排

在 `GameBoard` 的客户端启动入口按 Solo + 玩家 R4 + AI B-AI1 牌组条件挂接专用表现组件；非此组合不创建背景或沙盘。背景源图复制到 `Resources/VC5/Battlefield/`，代码按当前相机视口铺满。沙盘底板与格子装饰定位取实际 BoardSlot 变换，不以 Figma 像素替换操作坐标。现有高亮渲染层保持；得分区静态默认改为金色微呼吸，仅在没有交互高亮时显示。灯光和浮尘为无碰撞视觉层，停止/离开场景后随场景销毁；不增包依赖。

自动检查聚焦于背景资源能加载及模式隔离，不运行完整玩法套件。实际从 Menu Demo 入口进入对局，检查常态、棋子选中高亮与两个动态时刻的画面；结果回填后才能记为已验证。

实际相机的视口为屏幕中央 80%，不能只替换其世界背景，否则两侧会残留旧底色。背景/灯光/浮尘使用一台 Demo 专用全屏底层相机（无 AudioListener、无碰撞），棋盘仍由原相机呈现，原相机视口/尺寸/操作坐标不改。底层相机只渲染专用层，不复制棋盘或 UI。首次动态检查另发现 MaterialPropertyBlock 不能在 MonoBehaviour 字段初始化时创建，加入单项组件挂接回归检查后移至 Start 初始化；不以空判掩盖失败。

URP 实际复查：Base 相机不会按旧内置管线的 Depth-only 清屏方式保留底层颜色。专用底层相机负责全屏两侧，原游戏相机也渲染同一背景层覆盖中央；保持原相机的视口、投影、清屏与剔除配置，不使用改变操作坐标的相机堆叠。背景仅增加轻量视觉绘制，不重复棋盘/UI。

审核阶段记录：当时未修改 Unity 代码、场景、包依赖或 Assets 资源；未运行测试，未提交/推送或重打包。接入及验证结果另行回填。
