## 操作约定

- 队伍栏采用已审 Figma 302:86 的头像、生命比例条及数值、蓝色 AP 菱形、金色选中边框。点击头像也可选角色；HP≤50% 使用暖黄色，零 AP 显示行动耗尽，失去战斗能力明确灰化。
- 中立牌的执行者为当前选中己方棋子；进入战斗无选中时默认首名存活己方（守铃者）。职业牌自动匹配对应存活棋子，预览中明确显示执行者。不能为提高伤害或绕过 AP 限制而偷偷切换中立牌执行者。
- 卡牌点击进入瞄准态，鼠标悬停实时预览，点击合法目标执行；拖拽进入同一瞄准态，松开合法目标直接执行。非法目标、棋盘外/UI 上松手、ESC、禁用或回合切换均不扣 AP、不弃牌，并清理残留预览。
- 卡牌详情写明用法。推进拖向空格；重攻击/星火印/贯星术拖向敌人；鼓舞拖向其他友军；掩护拖向友军，该友军即执行者（自身护盾）；突入拖向敌人时依据鼠标靠近敌人的方向选择合法邻接落点，预览明确显示实际路径及推开位置，松手使用同一个完整计划。无合法落点则不执行。
- 基础行动仍先点击棋子打开行动菜单，选择移动/普攻/急救后，悬停目标显示预览、点击合法目标执行，取消不消费。没有额外确认按钮。

## 按效果展示预览

| 行动 | 瞄准范围 | 松手/点击前结果 |
|---|---|---|
| 基础移动、稳步推进 | 实际可达格（占位/障碍/步数规则） | 路径与落点、AP 前后、推进获得的护盾 |
| 普攻、重攻击 | 当前执行者射程与合法敌人 | 目标 HP 前后、实际扣血、护盾吸收/守护减伤、击败提示 |
| 星火印 | 3 格施法距离、视线及合法敌人 | 实际伤害、印记与期限 |
| 贯星术 | 3 格施法距离、视线及合法敌人 | 含印记/鼓舞的实际伤害及被消耗状态 |
| 掩护 | 存活且 AP 足够的己方棋子 | 目标作为执行者的 AP 与护盾前后（取较大值） |
| 战术鼓舞 | 辅助距离 2 内的其他友军 | 鼓舞状态、下一次伤害 +1、不叠加 |
| 急救 | 2 格距离内受伤的友军 | 实际有效治疗及 HP 前后，满血不可选 |
| 突入 | 当前可达且邻敌的落点/可攻击敌人 | 路径、实际伤害、敌方击退格；受阻不虚构额外伤害 |

范围提示与合法目标区分：理论射程不代表隔墙或满血目标也能执行。实时结果由 ActionPlanner + 克隆 BattleState 上 BattleResolver.Apply 计算，绝不修改真实战斗状态；释放时重新验证修订和目标。执行只通过 BattleController.Confirm，重复 EndDrag 不可重复消费。
