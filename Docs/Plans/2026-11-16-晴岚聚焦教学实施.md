# 晴岚聚焦教学实施计划

> 执行方式：主模型整合与实机审核，Luna 子代理负责独立代码／测试范围；采用 subagent-driven-development。禁止自动提交、推送、打包或覆盖现有未提交修改。

**目标**：将用户已批准的 11 月 16 日实机校准稿接入共享 AP 晴岚，框住实际对象，仅在指定动作成功且演出完成后推进。

**设计依据**：[关卡交互总稿](../晴岚炮台关卡、交互与界面设计.md)；Figma 文件 VC5 Demo 玩家引导 UI，页 483:7472，19 张状态图。用户本次明确批准实施，并要求实际框选准确。

**架构**：SharedBattleController 负责提交前校验及成功事件推进；独立 SharedFocusOverlay 负责动态锚点、金框、轻蒙层、局部说明与退出确认；SharedHud 提供实际 UI 锚点。规则、牌序、个人 AP 场景不变。继续现有用户指定工作区和已连接 Unity 工程，不创建缺失未提交共享 AP 内容的替代工作树。

**技术**：Unity 2021.3 / C# / uGUI；沿用 SharedPaper、BoardView、CardHandView 和当前动画。

## 公共接口合同

- 新枚举 FocusTutorialStep：Off, SelectMage, ReadInfo, ShortStep, DragMove, MoveTarget, DragSkill, SkillTarget, SelectArcher, BasicAttack, DragShield, EndTurn, Retain, Enemy, Ready。
- 控制器提供 FocusStep、FocusTutorialActive、FocusTitle、FocusBody、FocusChapter、FocusExitOpen、FocusRecoveryReason、FocusRestartConfirm、FocusRejectedAt、FocusEnemyActorId（只读）；ContinueFocusTutorial(), RequestSkipTutorial(), ResumeFocusTutorial(), ConfirmSkipTutorial(), RequestRestartFocusTutorial(), ConfirmRestartFocusTutorial(), ReportFocusAnchorMissing(string)。
- 拖入与移出为 DragMove/DragSkill 内的视觉子状态，由 IsDragging 和 PreviewExecutorId 判断；仅 DropCardOn 成功锁定执行者后进入目标步骤。
- 保留 SkipTutorial() 作为无交互的显式退出接口供已有规则交互测试使用；真实跳过按钮调用 RequestSkipTutorial()，必须确认。InitializeForTests 默认建立当前固定教学，其他交互测试应显式 SkipTutorial()，新教学测试不跳过。
- 图层不直接改战斗状态；所有成功动作、拒绝、取消和错误恢复由控制器处理。只在教程指定牌/人/点和留牌选弃上开放输入；不允许点牌再选人绕过拖牌教学。

## 任务与验收

- [x] 在改游戏代码前保存批准状态及本计划；记录本次前快照与现有脏文件。
- [x] 控制器：为错误选人、提前结束、错牌/错落点不改变 AP/手牌/位置写回归；接入 14 个步骤，等待演出，取消退回本牌拖入步，加入护盾和零弃牌路线。
- [x] UI：从 RectTransform.GetWorldCorners、实际 CardDragInput、UnitView 的可见 SpriteRenderer.bounds 和 Board.World 格角获取锚点，在 Canvas 内转换；LateUpdate 跟随布局与棋子。只画当前目标，不遮挡信息及拖拽预览。动态提示留/弃/补牌数量，全弃时不得声称保留牌存在。
- [x] 退出／异常：确认后保留已结算战局；未结算预览清除；恢复失败不给错误目标继续指令；重新开始教学需二次确认。胜负优先关闭教学，随机挑战不启用固定脚本。
- [x] Unity 编译、聚焦 PlayMode 回归、共享 AP 与原版必要回归；覆盖全部指定动作、错误和取消、动画未完不推进、镜头位移后的真实锚点（其他设备画幅待验收）。用当前场景截图验收短步足迹、手牌、棋子、普攻目标和留牌按钮。
- [x] 更新关卡总稿、审核记录与本计划，明确已实现及尚未进行的真人/触屏验证；不把静态图或控制器调用称作真人上手通过。

## 检查重点

卡牌重建/上浮后的实体锚点；高角色遮挡地板；拖拽松手同帧点击穿透；动画和过期事件提前推进；取消/退出后残留门禁。
