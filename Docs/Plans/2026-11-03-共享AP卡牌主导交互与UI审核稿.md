# 共享AP卡牌主导交互与UI审核稿

2026-11-03。状态：Figma V1八个可编辑审核画面已完成并回读/导出，等待用户审核；Unity未修改。

## 本次用户要求

1. 弃牌阶段点击选择要丢弃的牌，选中牌上浮；点击弃牌后只弃选中的牌，不选择不弃牌。
2. 点击出战小队或棋盘棋子，在游戏内以图文和示意图展示角色技能、攻击范围等信息。
3. 卡牌为主：点牌高亮可执行棋子，点棋子高亮可打出的牌；直接拖牌给棋子，不要求先点击棋子。拖到棋子时展示执行效果预览。
4. 常驻共享AP条。
5. 删除棋子短步/普通攻击操作弹框；简化基础行动，例如选人即出现短步落点。
6. 涉及UI先在Figma审核。本轮不将前次直接做Unity的授权用于本次改版。

## 拟采用的交互（助手提案，未审核）

### 弃牌与回合

- 替换现有“留牌选择”逻辑，不把点击选中解释成保留。
- 点击结束回合进入弃牌阶段；手牌仍在原位置，不另开遮挡棋盘的大弹窗。
- 默认零选中。选中的牌上浮并加“待弃”标签，再点击取消选中。上浮高度要与普通悬停区别，不能仅靠颜色。
- 有选中时确认按钮“弃牌并结束（N）”；没有选中时“直接结束（不弃牌）”。另有“返回战斗”，取消此次弃牌选择且不消耗资源。
- 确认后弃掉所选牌，敌人行动，下一己方回合补至5张。阶段内未确认不修改手牌；禁用出牌、走位、普攻，避免选中含义混淆。
- 按用户“不选择就不弃牌”解释：未选牌全部保留，替代旧最多保留2张限制。现有5张手牌时不弃就不会抽到新牌；显示“保留N张 / 下轮补M张”。此处是规则变更，应随审核明确，当前代码仍为旧留牌规则。

### 主界面与角色图解

- 复用晴岚和现有森林美术，在新的独立审核画框设计，不覆盖已有已审画框。
- 顶部中央常驻共享AP条：6格蓝色资源槽＋清楚的“全队AP 6/6”；预览时虚显将消耗的格数与余量，取消不扣费。
- 左侧小队为快速选人入口；选中角色的信息区包含立绘、HP/盾、武器伤害/射程、短步/普攻是否已用。
- 信息区用小棋盘示意攻击射程与命中形态：先锋四邻、射手3格单体、术师2格选主目标并波及其四邻。射程图与溅射图分开标注，禁止把溅射半径误当作施法射程；图注明示意，实际遮挡以战场高亮为准。
- 战技明确标“需战技牌＋1AP”，配推开前后位置、架弩增强、移位前后位置的小图。不再只写“战技 · 1 AP”。
- 未选中时信息区给简短目标/操作提示；角色信息与敌意图安排独立页签或独立区域，避免同时挤满长文。

### 卡牌优先与双向高亮

- 点牌：进入选执行者状态；所有当前可合法使用该牌的己方棋子、对应头像亮起，其他棋子降亮但可查看原因。不能依赖上次选中的角色。
- 点棋子：显示信息及可打出的卡牌；“可打出”按AP、完整合法行动是否存在、满血/护盾等条件计算，不仅检查费用。无效牌可看说明，不虚假标可用。
- 无论是否预先选人，拖牌悬停某队员时都以该队员为执行者预览：AP成本、武器参数、可选目标/落点、具体效果。旧选中者不参与此次结算。
- 只在松手时锁定执行者。治疗/护盾/架弩这种不需第二目标的牌，悬停显示准确变化，合法松手即执行。
- 攻击/猛攻：悬停执行者显示武器范围与合法敌人；还没选敌人时不伪造唯一伤害结果。松手锁定执行者后点敌人，指向目标显示实际HP/盾变化，最终确认才扣费。
- 机动：松手后选落点。突击：松手后选落点，再选敌人。术师移位：松手后选敌人，再选其四邻落点。全部步骤沿用同一张牌，不在中间扣费。
- 拖出合法区域、取消或返回均不消费。手机长按/按住目标可预览，不能只依赖鼠标悬停传达关键信息。
- 普通选人状态与卡牌模式互斥：卡牌流程中只显示本牌的目标/落点，防止误触基础行动。

### 移除操作弹框后的基础行动

推荐直接战场操作：选人后同时显示免费短步落点和可普攻敌人，以形状/图标区分，不只靠颜色。

- 短步可用：相邻合法空格显示脚印与“免费”，点击格子直接短步；走完后消失。
- 普攻可用：可攻击敌人显示剑标与“2AP”。指向时展示命中预览，点击敌人执行一次普攻；不再额外先点“普通攻击”按钮。
- 角色信息区常驻解释“点脚印短步 / 点剑标敌人普攻”；AP不足、次数已用或没有目标时显示原因。
- 换人更新信息与高亮；点击空白取消选人。已选牌时点击己方棋子优先解释为指定本牌执行者，不执行基础动作。
- 备选方案是将两种基础动作做成独立“基础行动卡”，但容易与真实手牌混淆，也多一次选择，本轮不推荐；仅作为审核时的替代方向。
