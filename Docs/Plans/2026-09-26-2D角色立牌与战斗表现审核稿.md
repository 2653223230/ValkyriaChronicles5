确认战场棋盘中的角色是否适合升级为日式二次元 2D 角色立牌，并检查小尺寸下的识别度、棋盘占位和战斗反馈可读性。首轮只审核美术方案与静态关键帧，不改 Unity 代码，也不调整玩法规则、AI 或 P2P。

- 角色采用透明背景立绘、清晰轮廓和赛璐璐上色，呈现为 2D 立牌，并配桌游风格的薄底座。

- 首轮角色为战场指挥官 R4，以及 B-AI1 重装前锋。B-AI1 沿用现有金发、红黑配色的精灵外形。
- 角色应融入当前棋盘画面，立牌和底座不能遮挡关键格位、棋盘信息或相邻单位。

## 动态表现建议（待评估，不代表已实现）

- 待机：轻微起伏，幅度克制，不影响格位判断。
- 移动：沿现有移动路径表现位移，并以清晰落地反馈结束；路径与落点规则保持现状。
- 射击：短促枪口闪光与弹道，避免长时间遮挡棋盘。
- 受击：短暂闪白并显示伤害飘字；持续时间和位置需以实际战斗画面评估。
- 护甲：提供简洁、易辨认的防护反馈，与普通命中区分。
- UI 切换：可评估简短的状态切换表现，不延长操作流程或改变交互规则。

以上均为后续表现方向建议。首轮可以先用静态关键帧表达意图，不将动画描述为已完成效果，也不据此承诺具体实现方式或性能结果。
