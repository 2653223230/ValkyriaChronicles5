## 关键提案

- 卡牌优先：点牌找执行者；直接拖给棋子，无需先选人；悬停预览采用接牌者，不沿用先前选中者。
- 双向高亮检查完整合法动作、AP与角色状态。无目标/满血牌显示原因；绿色可用、金色当前选择，配合文字不只依靠颜色。
- 共享AP常驻顶部，预览虚显消耗；真正执行前不扣费。
- 角色示意图使用无障碍理想范围，实际能否命中以战场合法目标为准。
- 基础动作直接在战场标记：脚印短步、剑标2AP普攻；卡牌流程内优先选本牌目标，不混入基础行动。
- 弃牌默认零选中，只弃所选。未选全保留，取消旧最多保留2张限制；下轮补到5张。此项是新规则提案，当前Unity仍为旧留牌机制。
