# 晴岚 V3 · Unity 场景验收

打开 SharedAP_Qinglan 场景并 Play。固定开局将「攻击」拖到射手身上可看射程、2点武器伤害及1点费用。松手锁定后，点巡兵才结算。点队员查看技能和范围图，点脚印免费短步，点剑标敌人进行2AP普攻。第一轮教学可跳过。结束回合点选要弃的手牌并确认。

| --- | --- |

| [拖给射手](drag.png) | 组件拖动事件显示跟手小卡、0个旧拖牌箭头、实际AP仍为6 |

全量PlayMode **71/71**，任务 `59ae9a3609dc48a8a8de89f6adc9250d`。最后调整预览文案、折叠详情和返回入口后，共享PlayMode **35/35**，任务 `9faf352053f74e658e9c51eff4e825f7`。晴岚实测攻击后AP由6变5，巡兵剩2HP，手牌由5变4。验证使用Unity组件事件及GameView，真人鼠标手感、安卓触屏和关卡平衡仍待试玩。
