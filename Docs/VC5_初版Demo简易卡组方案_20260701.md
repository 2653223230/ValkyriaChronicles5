# VC5 初版 Demo 简易卡组方案

记录时间：2026-07-01

## 设计目标

本方案用于制作初版 demo，用于体现游戏核心玩法和魅力，用于验证游戏底层玩法的可行性与趣味性，而不是局限于特定的卡牌、卡组。

核心设计概念：

> 这是一个卡牌 + 战棋的回合制游戏，以卡牌作为玩法核心，通过卡牌控制棋子的行为。棋子也拥有一定的主动行为或者被动技能，但是游戏核心是为了让玩家爽快地打牌。

本次方案重点：

- 卡牌效果尽量简单、直观、易上手。
- 尽量使用角色自身的攻击力、移动力、攻击范围等属性。
- 每张牌尽量只做一件事。
- 角色技能只做风格补强，不抢卡牌核心。
- 移动、攻击、靠近、撤退、护盾、治疗是首版 demo 的主要动作。

## 通用卡牌模板

| 模板 | 效果写法 |
|---|---|
| 普通移动 | 选择己方角色，移动至其移动力范围内的格子。 |
| 向前推进 | 选择己方角色，向敌方方向移动 X 格。 |
| 贴近敌人 | 选择己方角色，移动到一个敌人身边。 |
| 普通攻击 | 选择己方角色，对其攻击范围内的敌人造成等同其攻击力的伤害。 |
| 强力攻击 | 选择己方角色，本次攻击伤害 +X。 |
| 射程攻击 | 选择己方角色，本次攻击范围 +X。 |
| 撤退 | 选择己方角色，向己方方向移动 X 格。 |
| 护盾 | 选择己方角色，获得 X 点护盾。 |
| 治疗 | 选择己方角色，恢复 X 点生命。 |

## Demo 首发推荐

第一版建议优先做三套：

1. 基础教学卡组：给第一次玩的玩家。
2. 机动突击卡组：展示打牌让棋子冲起来的爽感。
3. 守点防御卡组：展示中央得分区争夺。

射击压制卡组可以作为第四套，因为远程会引入更多射程判断，但也很适合展示棋盘空间。
